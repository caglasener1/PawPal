# PawPal

PawPal is a virtual pet game written in Java.

The project started as an AP Computer Science A assignment and has since evolved into an independent software project. The goal is to create a virtual pet that encourages responsibility through realistic care mechanics, progression, and engaging gameplay.

## Current Features
- Create and name your pet
- Console-based menu
- View pet status
- Object-oriented design

## Planned Features
- Feeding system
- Sleeping system
- Health system
- Time progression
- Save/load system
- Achievements
- GUI
- Mobile application
